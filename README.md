# Pavan Teja Portfolio

## Project Description

This is a modern and responsive AI/ML portfolio website built to showcase my projects, skills, and experience in Machine Learning, Deep Learning, and AI application development.

The portfolio includes animated UI sections, responsive layouts, project showcases with GitHub and demo links, resume download functionality, and performance optimizations for production deployment.

## Running the Project Locally

### 1. Clone the Repository

```bash
git clone https://github.com/PavanTeja56/PavanTeja_Portfolio.git
```

### 2. Navigate to Project Folder

```bash
cd PavanTeja_Portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

### 5. Open in Browser

```bash
http://localhost:5173
```
